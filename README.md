# iphone-dimensions

Apple's published dimensions for every iPhone since the iPhone 7, as JSON and CSV. 43 entries. Height, width, depth, weight, display size, resolution and pixel density, in millimetres and inches, with the Apple tech-specs page each row was checked against.

This is the data behind [iphonesize.com](https://iphonesize.com), which draws any of these phones next to each other at true scale in 3D.

| iPhone 7 | 138.3 mm | 67.1 mm | 7.1 mm | 138 g | 4.7 in |

The folding iPhone Duo appears twice, once folded and once unfolded. Both rows share a `product_id`.

## Get the data

Straight from the site, with open CORS:

```
https://iphonesize.com/data/iphones.json
https://iphonesize.com/data/iphones.csv
```

From npm:

```
npm install iphone-dimensions
```

```js
import { phones, getPhone, findPhones, compare } from 'iphone-dimensions';

getPhone('iphone-15-pro');
// { name: 'iPhone 15 Pro', height_mm: 146.6, width_mm: 70.6, depth_mm: 8.25, weight_g: 187, ... }

compare('iphone-16', 'iphone-duo').delta;
// how much taller, wider, thicker and heavier the second phone is

findPhones('mini');
```

No dependencies. Node 18 or later. The raw files are exported too: `iphone-dimensions/data/iphones.json` and `iphone-dimensions/data/iphones.csv`.

## Fields

| Field | Meaning |
| --- | --- |
| `id` | Stable slug, also the page on iphonesize.com |
| `product_id` | Same as `id`, except the Duo's two rows share one |
| `state` | `folded` or `unfolded`, Duo only |
| `name`, `family` | Apple's marketing name and its generation |
| `announced`, `released` | ISO dates |
| `height_mm`, `width_mm`, `depth_mm`, `weight_g` | As Apple publishes them |
| `height_in`, `width_in`, `depth_in`, `weight_oz` | Converted, rounded to 2 decimals |
| `display_in`, `resolution_px`, `ppi` | Display diagonal, pixels, and Apple's stated pixel density |
| `compare_url` | The phone's page on iphonesize.com |
| `source_url`, `verified` | The Apple page the numbers were checked against, and when |

## Where the numbers come from

Every value is one Apple publishes on its own tech-specs pages at apple.com or support.apple.com. Nothing here is measured, estimated or scraped from a third party. `ppi` is Apple's stated figure, which can differ by a few pixels per inch from what you get by dividing the resolution by the marketed diagonal, because the marketed diagonal is rounded.

Depth is the body only. Apple does not publish camera bump height, so it is not here.

The files in `data/` are generated by the iphonesize.com build and copied in with `npm run sync`. Please do not edit them by hand in a pull request. If a number is wrong, open an issue with a link to the Apple page and it will be fixed at the source.
